Overview

About the project

A multi-vendor quick-commerce platform for groceries, with five connected roles (admin, vendor, customer, picker, and delivery partner) running on one backend.

The challenge

Fast grocery delivery needs many people working in sync: stores managing stock, pickers packing orders at hubs, riders delivering, and an operations team overseeing all of it. Off-the-shelf store builders could not handle that multi-role workflow.

Our solution

We built a single Node.js and MongoDB REST API serving every role, React and TypeScript admin and vendor panels, a customer web app, and Flutter apps for customers, pickers, and delivery partners. Onboarding flows cover vendors, pickers, and riders, and hub check-in screens support in-store operations.

Key features

  • Customer ordering with mobile-number OTP login
  • Vendor panel for orders, products, inventory, and hubs
  • Admin panel for platform-wide management and staff roles
  • Picker and delivery-partner apps for fulfilment
  • Self-serve signup flows for vendors, pickers, and riders
  • Hub check-in and hub display screens for dark stores
